# Articles

One Markdown file per article. The full how-to is in the website's README.md, under "Publishing an article".

- File name: `YYYY-MM-DD-short-name.md`, for example `2026-10-20-what-a-lead-is-worth.md`. The date is the publish date; the short name becomes the web address.
- Start with `_template.md`: copy it, rename the copy, write, and remove `draft: true`.
- To list something you published somewhere else (a LinkedIn article, a podcast, an interview), add a `link:` line with its address. The card on the Articles page then opens that address, and no page is made on this site.
- Files that start with `_`, and this README, are never published.
